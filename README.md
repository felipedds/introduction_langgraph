# introduction_langgraph
Foundation: Introduction to LangGraph
Foundation: Introduction to LangGraph course from: https://academy.langchain.com/courses/take/intro-to-langgraph

## Commands Virtual Environment
```mkdir src```                  # Create a folder /src
```mkdir tests```                # Create a folder /tests
```python -m venv .venv```       # Create a virtual environment
```.venv\Scripts\Activate.ps1``` # Activate it
```pip install -e .```           # Install the project and its dependencies

## Commands Langgraph
```langgraph dev```              # Install the project and its dependencies
